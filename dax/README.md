# `dax/`

Las medidas y tablas calculadas del modelo, en archivos `.dax`, agrupadas por la
pregunta de negocio que responden en vez de por orden alfabético.

Cada medida que no sea de lectura directa lleva su ficha: qué mide en lenguaje de
negocio, de dónde sale y **qué error se habría cometido sin ella**.

> Se llena en el paso 4.
